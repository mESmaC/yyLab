# Sprint/KDA PLE 150M training benchmark — 2026-09-13

**FINAL AVAILABLE RESULTS**. 44 valid receipts, 0 errors, 0 rejected and 0 unfinished. 0 of 32 planned baseline cells lack valid results.

Every update processes 32,768 input tokens. The baseline uses 8,192 micro tokens, five warmups and 20 measured updates; confirmations use 40 or more updates. Timed work includes forward, backward, clipping, fused GPU AdamW and input transfer. Packing, initialization, compilation warmup, evaluation and saving are excluded.

All arms use FP32 parameters, gradients and GPU optimizer moments with BF16 autocast. Regular full PLE uses **one** full-vocabulary table at every physical layer after layer zero, with a learned scalar gate; it does not use the historical four-full-table expansion. QR PLE uses four compositional quotient/remainder lanes matching Spalmer addressing, initialization and softmax reduction. This benchmark stores QR parameters in FP32, so it does not measure Spalmer's BF16-stored QR recipe. All arms retain the same full input embedding tied to the output head. See the [experiment definitions](../artifacts/sprint-ple-150m-20260913/experiment.json).

Hardware: NVIDIA GeForce RTX 5070, 11.94 GiB reported CUDA memory, 8 CPU threads. Software: fla-core 0.5.2, torch 2.11.0+cu128, transformers 5.16.1, triton-windows 3.7.1.post27. Initialization seed 42; input seed 43.
